# System Overview (project in development) 
Centralized system for cybersecurity incidents in organizations and companys  

## System analysis  
- Report the incident
- Track the investigation 
- Assign the incident to analysts 
- Record affected systems
- Assess the risk
- Monitor vulnerabilities
- Generate reports for management

## System Design 
-	Stores the incident
-	Calculates a risk score
-	Assigns it to an analyst
-	Links it to affected assets
-	 Logs all actions
-	 Tracks progress until resolve
